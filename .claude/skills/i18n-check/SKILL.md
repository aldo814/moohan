---
name: i18n-check
description: 다국어 규칙 준수를 검증한다 — 사전 키 일치(tsc), 하드코딩 문자열, 메타데이터/hreflang. 페이지 작업 후 또는 커밋 전 검증에 사용.
---

i18n 검증을 수행한다:

1. `npx tsc --noEmit` 실행 — 사전 키 불일치는 여기서 컴파일 오류로 잡힌다.
2. 빠른 자체 점검이 필요하면 여기서 직접 Grep으로 확인하고, **철저한 감사가 필요하면 i18n-auditor subagent에 위임한다** (하드코딩 문자열, 키 구조 diff, SEO 메타데이터, TODO 집계, locale 하드코딩까지 전 항목).
3. 결과를 `파일:줄 — 문제 — 권장 수정` 형식으로 보고하고, 위반이 없으면 "통과"로 명시한다.
4. 위반을 발견했으면 수정 여부를 판단한다: 사소한 것(문자열 하나 사전으로 이동 등)은 바로 고치고, 구조적인 것은 PLAN.md에 작업 항목으로 추가한다.
