작업 완료 기록 절차:

1. `PROGRESS.md`를 읽고, 방금 마친 작업을 `## 진행 중`에서 `## 완료`로 옮긴다.
2. 완료 항목에 다음을 한두 줄로 덧붙인다:
   - 생성/수정한 파일 목록 (경로)
   - 작업 중 내린 주요 결정 (있는 경우 `## 결정 사항`에도 기록)
   - 남긴 TODO (예: `// TODO: translate` 남은 위치)
3. 검증 결과를 명시한다 — `npx tsc --noEmit` 통과 여부, 빌드/테스트를 돌렸다면 그 결과. **실패한 상태로 완료 처리하지 않는다** (실패 시 "진행 중"에 두고 막힌 내용을 `## 막힌 부분`에 기록).
4. 작업 중 계획이 바뀌었거나 새 작업이 파생됐으면 `PLAN.md`를 갱신한다.
5. 완료 처리한 내용을 사용자에게 짧게 보고한다.
